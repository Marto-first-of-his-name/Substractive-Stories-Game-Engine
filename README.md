# Substractive-Stories-Game-Engine
A game engine tool inspired by the game ["I was seen as the weakest hero but I can secretly edit the metadata of the world"](https://bobafairy.itch.io/i-was-seen-as-the-weakest-hero-but-i-can-secretly-edit-the-metadata-of-the-world) on itch by BobaFairy. This tool allows the user to create games using the same mechanic as the aforementioned one by simply writing all the possibles sentences and adding images accordingly for each of them.

You can try out [a current version on itch](https://marto-makes-games.itch.io/ss-engine)
