# world-metadata-editor
A gamemaker tool based on the game "I was seen as the weakest hero but I can secretly edit the metadata of the world" on [itch](https://bobafairy.itch.io/i-was-seen-as-the-weakest-hero-but-i-can-secretly-edit-the-metadata-of-the-world) by bobafairy. This tool allows the user to create games similar to the aformentioned one by simply writing all the possibles sentences and adding images accordingly for each of them.

You can try out a current version on [itch](https://marto-makes-games.itch.io/world-metadata-editor-gamemaker)
